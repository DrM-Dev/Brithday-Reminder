# Birthday Reminder 0.1.1.35
*Never miss a birthday ever again :)*

_________________
*NOTE: make sure to place this program in your START-UP folder*

_________________
This program will remind you with the nearest birthday in a list you can add/remove birthday-dates to!
with a capacity of 120 dates [I think that's enough]
(if you want more, umm contact me haha)
:)

_________________
to build/modify this code you need the following packages:
1. Windsound
1. Pandas
2. Tkinter
3. Customtkinter
4. PIL
5. Datetime
6. sys & os
